# 2026-10-05 实测记录

本记录不公开服务器地址、用户认证信息或原始主机报告。测试对象为一台 Ubuntu KVM VPS：amd64、UEFI、2 vCPU、约 877 MiB RAM、40 GiB 单系统盘、IPv4 NAT、无可用 IPv6 路由；客户端为保留既有 TUN 的 Windows 电脑。以下数据只代表该时间段和这条线路。

## 系统重置

重置前备份已保存到另一台机器，以 AES-256-GCM 加密，密钥由 Windows 用户 DPAPI 保护；独立解密并读取了全部 228 个归档成员。它是选定配置/程序的备份，不是整盘镜像。

实测进入 Alpine RAM，并通过外部 SSH 核对 NIC、磁盘身份、内存和镜像 SHA-256 后才继续擦盘。原根分区及 EFI 分区标识发生变化；新系统为 Ubuntu 26.04.1 minimal、7.0.0-38-generic，保留 SSH 主机身份、公钥、原有可用密码登录、DHCP、时区和 1 GiB swap。公钥和密码登录分别验证，后续普通重启通过。

**首次实测并非全程无人干预通过。** 官方 minimal 镜像没有完整 initramfs；前置启动检查阻止了不完整系统重启。补充 initramfs-tools 和完整 initrd 的最终化逻辑后，在同一次安装的 RAM 环境恢复执行，未重复擦盘，成功启动并再次重启。该修复已进入发布脚本；未再额外擦盘进行一次从头到尾的无人干预复跑。

内核日志有可选 kexec handover scratch 区预留失败并禁用该可选功能的提示；正常启动、SSH、网络和包数据库通过，不能写成“内核日志零错误”。

## 网络优化

每组吞吐样本为 10 秒；以下比较组各重复 3 轮，表内为中位数。更改算法后重建监听器并核对真实连接的算法。

| 配置 | P1 下载 Mbps | P4 下载 Mbps | P1 上传 Mbps | P1 下载重传 | P4 下载重传 |
| --- | ---: | ---: | ---: | ---: | ---: |
| CUBIC + FQ | 33.45 | 33.94 | 30.37 | 5223 | 4296 |
| BBR + FQ | 34.07 | 33.89 | 30.15 | 2148 | 3537 |
| BBR + TBF 35 Mbps + FQ | 32.90 | 33.00 | 30.58 | 3 | 0 |

最后保留第三组，以少量吞吐换取明显减少的重传。随后 P1/P2/P4/P8 复测下载为 32.7–33.6 Mbps，每组 0–5 次重传。UDP 上传异常未修复，未宣称 BBR 改善了 UDP。缓冲保持原值；观测到可用内存至少约 563 MiB，内存 PSI avg10 为 0。

35 Mbps 是此线路的实测选择，**限制全机出口**；通用脚本默认仍不限速。自动超时回滚、新 SSH 后提交、手动切换前回滚、持久化服务及两次后续重启均实测。TBF JSON 字段兼容问题在真实试验中被保护检查拦截并回滚，修复后重测。优化器最终 SHA-256：`31b59d26081a673e25edeb4bb8047c43520f66dc5cc5452ccb9231f9c4b90cf2`。

## 代理实际安装

使用公开 dual-proxy-installer 原文件，SHA-256 `e4d987621a02127827d7ac9fd818367d6bf28f1ac112138b8772fce4eb6c12f1`，未修改脚本。实际安装 sing-box 1.14.2、申请 Let's Encrypt HTTP-01 证书，启动 Trojan TCP 443 / Hysteria2 UDP 443 和续期 timer。

两种协议直连均通过证书验证、HTTP/HTTPS、内容完整性、12 条逐步到达的 SSE、WebSocket 空闲 10 秒后回显、UDP 转发、错误密码拒绝。32 MiB 长样本：Trojan 下载/上传约 32.8/32.8 Mbps；Hysteria2 约 33.0/27.2 Mbps。重启后两种协议的新连接通过。

另测既有 TUN 路径：Trojan 可用但 RTT 约 355 ms；Hysteria2 未能连通，服务端对应来源的 UDP 计数为 0。没有改动既有 TUN。OpenAI API 返回 `403 / unsupported_country_region_territory`，未将其标成服务可用。

续期 service 本次正常执行（证书尚未到期，不是未来自动续期成功的证明）。手动调用证书重载 hook 曾中断一条正在上传的连接；独立补测通过，不声称重载无连接中断。卸载没有在保留服务的真实 VPS 上执行，其覆盖来自代理仓库原有隔离测试。

收尾：临时基准/代理测试监听器和 nftables 表均清理，本机测试客户端退出；原 v2rayN/sing-box 进程、默认路由和 TUN 状态保持一致。
